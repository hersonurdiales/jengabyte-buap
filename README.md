# JengaByte BUAP

Juego local de Jenga con preguntas de computación. Configura una partida para hasta cuatro personas, elige avatares y colores, y responde preguntas para mantener la torre en pie.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Descargar e iniciar

```bash
git clone https://github.com/hersonurdiales/jengabyte-buap.git
cd jengabyte-buap
npm install
npm run dev
```

Abre en el navegador la dirección local que indique Vite (normalmente `http://localhost:5173`).

También puedes descargar el proyecto como ZIP desde la página del repositorio usando **Code → Download ZIP**.

## Producción

```bash
npm run build
npm run preview
```

## Tecnologías

React, TypeScript, Vite, Three.js, React Three Fiber y Rapier.
